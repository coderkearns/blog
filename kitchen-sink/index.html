TypeScript

interface Post {
  title: string;
  date: Date;
  description?: string;
  tags: string[];
}

function formatDate(date: Date): string {
  return date.toLocaleDateString("en-US", {
    year: "numeric",
    month: "long",
    day: "numeric",
  });
}

const post: Post = {
  title: "Kitchen Sink",
  date: new Date("2026-03-20"),
  tags: ["meta", "test"],
};

console.log(formatDate(post.date)); // March 20, 2026

Python

from dataclasses import dataclass, field
from datetime import date


@dataclass
class Post:
    title: str
    published: date
    tags: list[str] = field(default_factory=list)

    def summary(self) -> str:
        tag_str = ", ".join(self.tags) if self.tags else "none"
        return f"{self.title} ({self.published}) — tags: {tag_str}"


post = Post("Kitchen Sink", date(2026, 3, 20), ["meta", "test"])
print(post.summary())
# Kitchen Sink (2026-03-20) — tags: meta, test

Interactive Component — Conway’s Game of Life

Conway’s Game of Life is a zero-player cellular automaton devised by mathematician John Conway in 1970. Four rules govern every tick:

  1. A live cell with 2 or 3 live neighbours survives.
  2. A dead cell with exactly 3 live neighbours becomes alive.
  3. A live cell with fewer than 2 or more than 3 neighbours dies.
  4. All other dead cells stay dead.

From those four lines of logic, remarkably complex, organic-looking patterns emerge. The grid below starts with a Gosper Glider Gun — the first pattern ever discovered that grows without bound, continuously firing small five-cell “gliders” across the grid.

Gen 0  ·  Alive 0

Click or drag on the grid to draw cells, then press Play.
